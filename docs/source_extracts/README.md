# Source reading aids

These files were generated locally from the two supplied scanned PDFs. The text files and OCR JSON are imperfect reading aids, not verified transcriptions. In particular, long prose lines, equations, subscripts, and symbols may be missing or incorrect. Use the page images and source PDFs for precise interpretation.

- mtp1.txt and mtp1_ocr.json cover all 33 PDF pages of MTP 1.pdf.
- subsidence.txt and subsidence_ocr.json cover all 28 PDF pages of subsidence pdf .pdf.
- images contains upright rendered page images. The textbook photographs were rotated 90 degrees for reading.
- Contact sheets provide page navigation. eq10_detail.png enlarges the amplitude equation on MTP PDF p.22.
